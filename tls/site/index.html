安装 zoetrope 本地根证书

这个页面走的是明文 HTTP，所以不会有证书警告——它的唯一用途就是让你先把根证书装上， 之后 https://10.0.30.61/ 才不会报警告，Service Worker 也才能注册。

下载 ca.crt

只需要装这一次，装完这台设备以后都不用再管。

为什么必须装：Service Worker 只在安全上下文可用。 局域网 IP 上的 http:// 不满足；而 https:// 若证书不被信任，浏览器会拦在警告页，Service Worker 同样注册不了。

Windows

  1. 下载 ca.crt
  2. 双击 → 安装证书 → 存储位置选本地计算机
  3. 下一步 → 将所有的证书都放入下列存储 → 受信任的根证书颁发机构 → 完成
  4. 完全关闭并重开浏览器

macOS

  1. 下载 ca.crt，双击导入钥匙串访问（选「系统」）
  2. 在钥匙串里找到 zoetrope Local CA，双击
  3. 展开信任，把「使用此证书时」设为始终信任
  4. 关闭窗口并输入密码确认，然后重启浏览器

Linux (Chrome / Chromium)

sudo cp ca.crt /usr/local/share/ca-certificates/zoetrope-local-ca.crt
sudo update-ca-certificates

Chrome 有自己的 NSS 库时，还需要：certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n zoetrope -i ca.crt

Firefox（独立信任库）

设置 → 隐私与安全 → 证书 → 查看证书 → 证书颁发机构 → 导入 → 勾选「信任由此 CA 标识的网站」。

Android

设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书 → 选择 ca.crt。 注意：Android 上用户安装的 CA 对 Chrome 生效，但部分 App 不认。

iOS / iPadOS

  1. Safari 打开本页下载，或在「设置 → 已下载描述文件」中安装
  2. 设置 → 通用 → 关于本机 → 证书信任设置 → 打开该 CA 的开关（这一步常被漏掉）

装好后访问 https://10.0.30.61/。 证书由 tls/gen-certs.sh 生成，叶子证书 397 天有效，到期重跑该脚本即可。
